## 2. cowork 사실 대조 (공개 파일 기준)

### 2-1. RQ4 꼬리 방향 — 브리핑 문면 정정
- 출처 `results/sealed_publish/…v3_null_MAIN___sealed__null_result.json`: `sidedness` = **one-sided-upper** · `p_emp = (1 + #{T_b ≥ T_obs})/(B+1)` · **B = 1,000**(global·family 각각) · family `n_ge_obs` = 965 · global `n_ge_obs` = 214 · mc_se family 0.0058 / global 0.0130 · T 정의 = rep1(seed 201) M2b macroAP.
- 따라서 family p 0.965 = **family 내부 재배치 1,000개 중 965개가 관찰값 이상** → 관찰값은 분포 **하위 쪽**이다(브리핑의 「한가운데」는 cowork 오기).
- 보고 규칙: 판정은 «기준 미충족» 그대로. 하위 꼬리 p 는 사전지정이 아니므로 **계산·보고하지 않는다**(D). 서술은 「관찰값 이상인 재배치 비율 = 96.5%(family) / 21.5%(global)」라는 사실 문장까지만.
- ★ 정정(2026-10-08 · 블록 BH 러너 지적 · cowork 확인): global 비율은 `n_ge_obs/n_permutations` = 214/1,000 = **21.4%** 다(21.5% 는 p_emp = 215/1,001 을 비율로 오기한 cowork 오류). family 965/1,000 = 96.5% 는 맞음. 원고 문면 = 「214 of 1,000 (21.4%; p_emp = 0.215)」.
- 브리핑의 RQ4 B 표기 누락도 보충: RQ4 는 B = 1,000(나머지 sign-flip·BCa 는 10,000 · ⑧ 은 100,000).

### 2-2. sign-flip 대상 (U4)
- `unblinding_independent_check.py` 계획 `perm_protocol_verbatim`(= `sap/signflip.py _perm_deltas` 문면): 동전이 나온 군의 **행에서 두 arm 예측을 맞바꾼 뒤 전체 행에서 macroAP 를 다시 계산** → 군별 AP 합산이 아니다. Δ 정의와 같은 통계량을 재계산하므로 회신의 우려는 해당 없음. 방법 절에 이 1문장 명시.

### 2-3. 양성 0 PT (U5)
- `sap/bootstrap.py` L8–11 · `sap/metrics.py` L12–13: eligible PT = 원 평가셋 고정 370(global 양성 ≥10) · replicate·jackknife 표본 내 양성 0 PT 는 그 표본 macro 에서 제외(분모 변동) · 재선정 금지. 동결 규칙 존재 → 방법 절에 명시만.

### 2-4. OOF 경계 (U7)
- λ: `docs/33` L663 — 외부 fold 학습셋 안의 1/9 scaffold 내부 분할(GIN inner-validation 과 동일)로 선택 → 평가 약물 미사용.
- RF_tuned: `post_interim_freeze_v1_0.json` `holm6_rf_tuned.hyperparameters_source` = 「pre-confirmatory fair-tuning result (`v1_RF/results_fairtune`) verbatim · selected_by valid_macro_pr · budget 16」. **확증 데이터로 재튜닝은 없지만, v1 검증 분할의 약물이 v3 확증 test fold 약물과 겹치면 RF_tuned 하이퍼파라미터에 평가 약물 정보가 간접 반영**됐을 수 있다. 영향 방향 = RF_tuned 기준선이 유리해짐 → ⑥ Δ(M2b − RF_tuned)를 보수적으로 만드는 쪽. 판정(⑥ 기각 0)에는 영향 없음. → 한계 서술 + 겹침 실측(Z4).

### 2-5. Monte Carlo 해상도 (U10)
- sign-flip p = (1+c)/(B+1), B = 10,000 → 최솟값 1/10,001 ≈ 0.0001. 표의 p = 0.0001 은 **c = 0 (최솟값)** 이다(②·C-CAP·S-RQ1·S-RQ1b·⑦h·③fsc).
- ⑧ p = (1+c)/(B+1), B = 100,000 → 0.00022 = c 21.
- RQ4 B = 1,000 · mc_se 위 §2-1.
- 표 각주에 산식·B·최솟값 명시, «p < 0.0001» 등 해상도 이상의 표기 금지.
