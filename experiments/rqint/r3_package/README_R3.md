# R3 환경 확인 프로브 — 실행 안내

안녕하세요. 부탁드린 **환경 확인 1건**입니다. 아래 3줄만 실행해 주시면 됩니다.
**1분 이내**에 끝납니다.

---

## 실행 (3줄)

```bash
pip install -r requirements_probe.txt
python3 collect_env.py
python3 run_rqint_probe.py
```

## 보내주실 것 (2개)

1. `env_<12자리 영숫자>.json` — 두 번째 줄이 만드는 환경 명세
2. `probe_numeric_core.sha256` — 세 번째 줄이 만드는 결과 요약

(원하시면 `probe_result.json` · `probe_run.log` 도 함께 주시면 좋습니다. 필수는 아닙니다.)

---

## 이게 뭔가요

논문 통계 절차의 승인 조건 중에 **"다른 사람이 다른 컴퓨터에서 같은 코드를 돌렸을 때
같은 숫자가 나오는지 확인"** 이 있습니다. 이번 실행은 그 **본 확인 전에 플랫폼이 맞는지만
보는 사전 점검**입니다.

- 입력 데이터는 **전부 난수로 만든 합성 데이터**입니다. 실제 연구 데이터는 이 패키지에
  **한 바이트도 들어 있지 않습니다.**
- 네트워크에 접속하지 않고, 파일을 만들지도 지우지도 않습니다(결과 파일 3개 제외).
- **정답 해시는 일부러 넣지 않았습니다.** 보내주신 값을 저희가 받아서 대조합니다.
  (기대값을 알려드리면 "독립 확인"의 의미가 없어집니다.)

## 무엇을 검사하나요

프로브는 검정 구현의 성질 **6가지**를 확인합니다 — 가환성(R6-1) · 영효과 시 p=1(R6-2) ·
전체 교환 반대칭(R6-5) · 군 재라벨 불변(R6-6) · 재실행 결정성(R6-7) ·
독립 참조구현 대조(R6-9).

나머지 3가지(R6-3 균등성 · R6-4 여집합 감사 · R6-8 완전열거)는 축소 규모에서
합격기준이 성립하지 않아 **본 확인 때** 실행합니다.

## 규모

N=60 · K=8 · G=12 · 동전벡터 64개. 저희 장비 기준 벽시계 **약 8초**입니다.

## 환경

`requirements_probe.txt` 의 버전이 안 맞아도 **괜찮습니다.** 오히려 환경이 다른 편이
확인 목적에 부합합니다. 설치가 번거로우시면 이미 있는 numpy/scikit-learn 으로 그냥
돌리셔도 됩니다 — `collect_env.py` 가 실제 버전을 기록합니다.

Python 은 **3.10 이상**이면 됩니다.

## 개인정보

`collect_env.py` 는 컴퓨터 이름을 **원문으로 저장하지 않습니다**(해시 앞 12자리만).
사용자 이름이 들어갈 수 있는 절대경로도 수집하지 않습니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `run_rqint_probe.py` | 프로브 본체 (이것만 실행) |

| `canonical.py` | 결과 JSON → 비교용 해시 (프로브가 자동 호출) |

| `requirements_probe.txt` | 권장 버전 |
